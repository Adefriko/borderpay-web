# BorderPay QR Coin-to-Coin (Kelompok 8 - Blockchain TI-B)

Prototipe aplikasi web berbasis blockchain untuk transfer dan pertukaran koin simulasi (`mUSD`, `mEUR`, `mJPY`) menggunakan QR pada jaringan **Ethereum Sepolia Testnet**.

> **Disclaimer Akademik:** Seluruh token bersifat mock ERC-20 tanpa nilai ekonomi dan proyek ini merupakan demonstrasi akademik non-komersial.
