# BorderPay — Project & Agent Guidelines

## Anti-Slop Filter Guidelines
This project integrates [Anti-Slop](https://github.com/miqdadbadjuber/anti-slop) to maintain clean, deliberate, and human-crafted quality across all user interfaces, copywriting, and code.

### Core Rules:
1. **User Interface (`/antislop-ui`)**:
   - Avoid generic AI tropes: cliché purple gradients, unnecessary sparkler emojis, pill badges, and fake latency metrics.
   - Every visual decision must serve a clear purpose (hierarchy, clarity, branding).
   - Maintain the institutional Blue Glassmorphism design system defined in `docs/DESIGN_SYSTEM.md`.

2. **Copywriting (`/antislop-copywriting`)**:
   - Write clear, concise, and direct sentences.
   - Do not use hollow corporate buzzwords, exaggerated marketing claims, or robotic emoji bullet lists.

3. **Code Hygiene (`/antislop-code`)**:
   - Write clean, expressive code without verbose comments that merely restate what the code obviously does.
   - Avoid unnecessary abstractions or bloated boilerplate.

4. **Mobile & Responsiveness (`/antislop-layoutmobile`)**:
   - Ensure clean stacked mobile layouts without clipped text or overflowing elements.

5. **Accessibility (`/antislop-human`)**:
   - Ensure WCAG AA contrast compliance and clear keyboard navigation.
